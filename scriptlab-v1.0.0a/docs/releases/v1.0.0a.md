# ScriptLab V1.0.0a — Primera release pública

**Laboratorio de guiones para YouTube, 100 % en tu navegador.**
Medí la salud (ICN), la retención estimada (APV) y el arco emocional de tu
guion *antes de grabar*. Sin cuentas, sin servidores, sin tracking.
En español; UI en rioplatense.

## ✨ Highlights

- **Motor `combined-2.0.0` auditado y validado con literatura**: merge de dos
  builds previas con todos los bugs corregidos y pesos revisados contra
  papers verificables.
  - **Arco emocional integrado al APV** (peso 0.11): los *flips* de
    emocionalidad predicen engagement (Berger et al. 2026, JAMS/Springer —
    efecto causal, N≈40k; Song et al. 2023, eNeuro).
  - **Bonus CTA escalado por calidad** (`8 × calidad/100`; estudio Wistia:
    mid-roll 16.95 % vs post-roll 10.98 %). Sin CTA real = +0.
  - Citas corregidas: eliminadas referencias no verificables heredadas.
- **94/94 tests en Node** cubriendo el motor completo (CI con GitHub Actions,
  Node 20/22).
- **E2E en Chromium real: TODO OK** — paridad Node↔browser exacta (ICN/APV
  18/31 %), CSV con BOM verificado por bytes, onepage 100 % autocontenida
  abierta con doble click, y fase IA con robertuito real (POS +0.96 /
  NEG −0.98; APV 54 % → 48 % al integrar el arco). Evidencia: `docs/e2e/`
  y `docs/PRUEBAS-E2E-V1.0.0a.md`.
- **Benchmark reproducible** con 4 guiones de referencia:
  Salud **18 / 67 / 81 / 67** · APV heurístico **31 / 68 / 80 / 63**
  (malo / medio / espectacular / mentes perturbadas) — ranking intuitivo
  correcto en los 3 años de builds medidos.
- **Trazabilidad total**: la fórmula del APV se ve mano a mano dentro de la
  app y en cada export; el desglose de pesos y fuentes con links está en
  `metricas.html`.

## 🚀 Cómo correrla

```bash
git clone <este-repo> && cd scriptlab
python3 -m http.server 8000     # o: npm start
```

→ **http://localhost:8000/scriptlab.html**
(los módulos ES y workers necesitan HTTP; doble click en `file://` no aplica
a la app, sí a los *exports* HTML, que son 100 % autocontenidos).

El **Modo IA** (opcional) descarga 2 modelos (~110 MB) que corren localmente;
el modo heurístico ya da Salud, APV, curva, factores y carga cognitiva sin
descargar nada.

## ⚠️ Limitaciones conocidas

- Safari/Firefox sin E2E automático todavía (Chromium 151 sí cubierto).
- La descarga de modelos (~110 MB) pica a ~1 GB de RAM: en entornos de 2 GB
  puede matar el tab (OOM); con swap o más RAM no hubo problema.
- Algunos pesos siguen marcados `[NO VALIDADO]` — listado honesto en
  `docs/RESEARCH-PASO3.md` §3.1.
- Los proyectos guardados viven en IndexedDB del navegador; borrar los datos
  del sitio los elimina (exportá JSON como backup).
